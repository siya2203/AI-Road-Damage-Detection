# AI-Road-Damage-Detection
An AI-powered computer vision system designed to detect and classify road damage using Deep Learning and Object Detection techniques.

# Project Overview
Road damage, including patholes and cracks, can create serious safety risks and increase vehicle maintenance costs.

This project aims to develop an automated road damage detection system that analyzes road images and identifies damaged areas using computer vision and deep learning.

# Objectives
-> Detect patholes and road cracks automatically.
-> Identify and localize damaged regions using bounding boxes.
-> Classify different categories of road damage.
-> Display detection results with confidence scores.
-> Develop an interactive application for image-based detection.

# ⚙️ Installation

Clone the repository:

-> git clone https://github.com/YOUR-USERNAME/AI-Road-Damage-Detection.git

-> Navigate to the project directory:

cd AI-Road-Damage-Detection

-> Create a virtual environment:

python -m venv venv

-> Activate the environment (Windows):

.\venv\Scripts\Activate.ps1

-> Install dependencies:

pip install -r requirements.txt
